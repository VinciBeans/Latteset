Crema T

PURE GEOMETRY · 实心圆 + T

俯视的浓缩咖啡杯：实心圆面就是 crema 咖啡脂，品牌首字母 T 直接压在 crema 上。一个元素、两层含义——最少的形状、最稳的结构，16px 下依旧清晰。

Dot Cup

DOT MATRIX · 圆点矩阵

用圆点一格一格"冲"出一杯咖啡：杯口宽、杯身收窄、杯碟垫底，蒸汽两粒点。像素化的轻松感，像咖啡机的压力表盘——年轻、好玩、可动。

Steam Waves

LINE SYSTEM · 弧线 + 双 S 曲线

杯体只剩一条弧线，蒸汽是两道 S 曲线。右侧那道珊瑚色的冒得更高——刚出的那杯，还烫着。极简线条，编辑部气质，也是典型的"热饮"科学符号。

Hot Steam Cup

DOTS + GEOMETRY · 实心杯 + 漂散点

实心浮雕杯身配杯碟，蒸汽是三粒向右上漂散、渐渐细小的圆点——不对称构图带来动势。重量感集中在下方，蒸汽随身带走"即时感"。

Pulse Ring

LINES + GEOMETRY · 环 + 脉冲线

杯子俯视成一只环，环内是一条实时编译的脉冲线——编辑 → 编译 → 出 PDF，心跳般的响应。顶部两粒蒸汽提醒你：它仍然是热的。

Rising Nodes

NODE NETWORK · 节点上升流

蒸汽被画成一条从左下升向右上的节点链：节点越升越小，直到那枚珊瑚色火花——刚出炉的瞬间。AI 时代的气质，把"即时感"变成一条上升流。

Fat T

MODULAR GRID · 圆角方块拼 T

五个圆角方块直接拼出一个粗 T，头顶一粒蒸汽点。最年轻、最直接、最有"开发者工具"气质——模块化、可由点阵运动，是离字标最近的一个。

Line T

LINE FILL · 横线织成 T

圆内横向排列的线条，以长短排序织出字母 T——像代码行、像文本流、像咖啡机的水平条纹。笔画融入载体，低调而有技术含金量。
